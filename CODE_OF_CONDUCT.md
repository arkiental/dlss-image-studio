# Community conduct

Be respectful, constructive and specific. Welcome contributors of different
backgrounds and experience levels. Critique the work, not the person.

Harassment, threats, discriminatory language, doxxing, spam and deliberate sharing
of another person's private material are not acceptable. Do not post confidential
renders or credentials in issues, discussions or pull requests.

Maintainers may edit or remove content, close discussions, or restrict participation
to protect the community. Apply these expectations consistently and proportionately.
To report a concern, use an available private GitHub contact channel for the
repository owner. If none is available, ask for a private channel without posting
sensitive details publicly. Security vulnerabilities use SECURITY.md instead.
