# Current release notes

[DLSS Image Studio 0.2.2](releases/v0.2.2.md) documents the current Windows release:
a compact monochrome workspace, adjustment search, clearer comparison controls,
resizable inspection and improved history, snapshots and preset discovery.

Downloads include Setup, a portable ZIP and SHA-256 checksums. Neural enhancement
requires the separately installed Visual Enhancer v13.2 runtime; it is not bundled.

The linked notes distinguish frontend/browser validation from earlier hardware
evidence and list the native workflows not retested for this update.
Historical notes remain in [0.2.1](releases/v0.2.1.md).
