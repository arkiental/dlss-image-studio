# DLSS Image Studio 0.2.2

This update improves the editing workspace and fixes several interaction problems.
The native processing backend and project format are unchanged.

## Download

- **Setup.exe** installs Studio per user and includes Microsoft's offline WebView2 installer.
- **Portable.zip** runs without installing Studio; WebView2 must already be installed.
- **SHA256SUMS.txt** contains checksums for both downloads.

Neural enhancement requires the separately installed Visual Enhancer v13.2 runtime.
No provider, models or NVIDIA runtime DLLs are bundled. Conventional finishing
works with Neural Adjustments off. Windows 11 x64 is the tested platform; releases
are unsigned.

## Changes

- Compact monochrome controls, clearer Settings, and Workspace tabs for Masks,
  Passes, Presets and Batch. Folded inactive neural controls and smaller export
  actions give the image more room.
- Find adjustment / Ctrl+K opens the matching section and focuses its control.
  Before and After buttons, the source filename and preview labels identify the view.
- Resize the detail selection using its eight handles, or move and resize it with
  the keyboard. The floating inspector follows Before/After and temporary original view.
- Numeric Escape cancels an edit; pending-edit Undo retains Redo. Zoom entry,
  keyboard navigation and Settings focus handling are more consistent.
- History names the edited controls. Snapshots have unique names, inline rename,
  deletion Undo and selection feedback that follows the current edits.
- Workspace Presets searches built-in looks and saved presets. Mask instructions
  describe the selected mask type.

## Verification and limits

Frontend unit tests, the production frontend build and browser workflow checks
passed at 1536×1024 and 1080×840. Synthetic transport checks cover request ordering
and failure handling; they do not run the neural provider.

This UI pass did not launch the native application or initialize DLSS. Earlier
RTX 4090/provider verification is recorded in
[the verification documents](https://github.com/arkiental/dlss-image-studio/blob/v0.2.2/docs/PROFESSIONAL_VERIFICATION.md);
it is not a new hardware test of 0.2.2. Native DLSS evaluation, desktop dialogs,
per-monitor DPI transitions and fresh Setup/portable execution were not retested
for this update. No new GPU quality or performance claim is made.

Neural output remains SDR, including the reversible HDR working-copy path.
The complete proposed professional feature list is not implemented; see
[supported features and limits](https://github.com/arkiental/dlss-image-studio/blob/v0.2.2/docs/PROFESSIONAL_WORKSPACE.md).
