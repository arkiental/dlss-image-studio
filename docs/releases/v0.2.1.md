# DLSS Image Studio 0.2.1

Windows render finishing with the original dark/gold workspace, float/HDR editing,
50 included creative LUTs, masks/passes, snapshots, projects and batch export.

## Download

- **Setup.exe** — recommended. Per-user installation, Start menu entry and included
  offline WebView2 installer. No developer tools or separate MSVC runtime install.
- **Portable.zip** — extract and run `dlss-image-studio.exe`; requires existing WebView2.
- **SHA256SUMS.txt** — checksums for both downloads.

**Neural runtime is not included.** Visual Enhancer v13.2 must be obtained from its
author and selected in Settings. Its license prohibits bundling without written
permission. For conventional finishing, turn off Neural Adjustments.

## Changes

- Restore the compact studio layout and draggable sliders, floating inspector and snapshots.
- Add 50 licensed LUT presets, CUBE import, strength/bypass and portable LUT project assets.
- Correct the neural bridge to use real 16-bit input/output. HDR imports automatically
  use a labeled reversible SDR working copy; original HDR source data is preserved.
- Add release packaging, installation and user guides, contributor and security guidance.

## Verification and limits

Real neural evaluation and 16-bit output were verified on an RTX 4090 with the
separately installed v13.2 provider. Automated frontend, native and UI transport
checks are separate from hardware evaluation; hosted CI does not prove DLSS.
See the repository verification documents for details.

Windows 11 x64 is the tested platform. Releases are unsigned. Every GPU model and
fresh Windows configuration has not been tested. Neural output is SDR, including
the HDR working-copy path. The full proposed professional feature list is not
complete; consult the implementation matrix. No runtime DLLs/models are bundled.
